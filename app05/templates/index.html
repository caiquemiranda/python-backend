Sobre o Projeto

Este é o quinto projeto da série de exemplos de backend com Python. Ele demonstra:

  • Autenticação de usuários com Flask
  • Proteção de rotas usando decoradores
  • Criptografia de senhas
  • Gerenciamento de sessões
  • Implementação de permissões básicas (cada usuário só pode gerenciar seus próprios posts)
